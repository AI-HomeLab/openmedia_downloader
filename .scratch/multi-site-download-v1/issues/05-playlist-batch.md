# 05 — 播放清單批次下載

**What to build:** 貼 YouTube 播放清單或 B 站合集連結，App 逐項下載；
用戶看得到「第 N 項 / 共 M 項」整批進度與當項進度；單項失敗只重試該項，
不整批重來，不打包 ZIP。

**Blocked by:** 04 — 音檔 mp3 模式.

**Status:** ready-for-agent
